# A game for the Pygame Community Summer Game Jam 2026
An RTS about expanding your colony of technological ants!  
Made by ***Lowland Palms***

# Info
This game was made for the Pygame Community Summer Game Jam 2026. The theme we were given was ***"Swarm"***. Our first thoughts went to swarms of insects, and very quickly the idea of ants came to us. Ants are of course famous for their large colonies and their cooperation, so we wanted to use this to create an RTS about expanding your ant colony! To make it all more interesting, we decided to make these ants technologically advanced!

# Installation
On [the game's Itch.io page](https://jreesw.itch.io/rise-of-the-techno-ants) you can find an executable for Windows.  

Alternatively the source code can be downloaded and ran/built manually. In that case, make sure to grab a somewhat up-to-date Python version (the game was developed in Python 3.14) and follow these steps:  
 - Install the required modules using `pip install -r requirements.txt`  
 - Run main.py
  
To build the game, run `build.bat` if you're on Windows.

# How to play
The entire game can be played with only your mouse. The controls are usually:
 - `LMB` to select things
 - `RMB` to tell units where to go
